# RentalManager – Style Guide

Versión: 1.0

---

# Filosofía

RentalManager no es una página web.

Es una herramienta profesional para la gestión de propiedades y reservas.

El diseño debe transmitir:

- confianza
- orden
- calidez
- estabilidad
- facilidad de lectura

Se evitarán efectos innecesarios, colores estridentes y elementos decorativos que no aporten información.

El objetivo es que el usuario pueda trabajar durante horas sin fatiga visual.

---

# Identidad visual

Inspiración:

- arquitectura mediterránea
- madera
- ladrillo
- piedra
- materiales naturales

El estilo debe ser elegante, sobrio y cálido.

# Filosofía del color

Los colores cálidos representan la identidad de RentalManager.

Los colores funcionales representan estados.

Nunca deben mezclarse ambos conceptos.

Ejemplo:

Terracota → botón

Verde → reserva confirmada

Rojo → incidencia

Naranja → salida próxima

Azul verdoso → información

De esta forma el usuario identifica rápidamente qué elementos pertenecen a la interfaz y cuáles representan información.
